## Proposed Changes

### 1. Panel Height (60vh)
We will modify `src/components/TrackLibrary.tsx`:
- Change the expanded panel outer wrapper from `max-h-[80vh]` to `h-[60vh]` (and `h-0` when closed).
- Set the content wrapper to `h-[calc(100%-45px)] overflow-y-auto` to fill the container perfectly.
- Set the scrollable lists inside tabs to `max-h-[42vh]` so they fit perfectly within the 60vh panel.

### 2. Shazam API integration in Backend
We will modify `backend/proxy.js`:
- In the `/api/recommend` route:
  - If a `trackId` (YouTube video ID) is provided, call `fetchRapidAudio(trackId)` to get a direct MP3 download URL.
  - Call the Shazam Recognition API (`https://shazam-song-recognition-api.p.rapidapi.com/recognize/url`) with the MP3 URL.
  - Fetch similar tracks using the `relatedtracksurl` from the Shazam response.
  - Resolve YouTube video IDs in parallel for the top 8 tracks.
  - Return resolved tracks as recommendations.
  - Fall back to the existing YouTube search logic if any step fails or the track is local.

### 3. Frontend Prop Updates
- [MODIFY] `src/components/TrackLibrary.tsx`:
  - Accept `currentTrackId` in `Props`.
  - Pass `currentTrackId` in query parameters when calling `/api/recommend`.
- [MODIFY] `src/App.tsx`:
  - Pass `currentTrackId={activeTrack?.id}` to `<TrackLibrary />`.
