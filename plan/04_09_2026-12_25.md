# Feature Plan: Vinyl Playback Completion Reset & UI Interaction Hardening

**Date:** 04/09/2026 12:25  
**Target:** DJ Pro Master (`mobile/`)

---

## 1. Objectives & Overview
Fulfill the two user-requested enhancements:
1. **Vinyl Playback Completion & Position Reset**:
   - When a song ends (reaches duration while not looping):
     - The vinyl jog wheel must stop spinning immediately (`isPlaying = false`, angular velocity = 0).
     - The playhead/cursor position must return to the beginning of the song (`Duration.zero` / 0:00.00).
     - The display must not remain at `remaining: 0` while spinning. It should cleanly show the reset track at `00:00.00` (or full duration remaining) with transport in stopped/paused state.
2. **Context Menu & Text Selection / Copy Prevention**:
   - Disable right-click / long-press contextual menus on the entire application UI (browser context menu, webview context menu, text selection context menu).
   - Prevent text selection and text copying across all UI labels, meters, BPM displays, track titles, and buttons, giving the application the feel of a dedicated, touch/mouse-driven hardware DJ console.

---

## 2. Root Cause Analysis & Architecture

### Issue 1: Vinyl Keeps Spinning at Song End & Remaining Stuck at 0
- **Root Cause**:
  1. In `DeckProcessor` (`dj_scratch_processor.js`), when `pos >= this.frames - 1`, it was clamping `pos` to `this.frames - 1` and setting `this.playing = false`. However, `this.position` remained at the last frame (`frames - 1`), meaning `position` was at track end, and `remaining` computed to 0.
  2. In `WebDeckAudioBackend` (`deck_audio_backend_web.dart`), when the buffer source fallback or worklet finished, `_positionFrames` was never reset to 0.
  3. In `DeckAudioBackendIO` (`deck_audio_backend_io.dart`), on `_player.onPlayerComplete`, it only did `_playing = false` without seeking back to `Duration.zero`.
  4. In `AudioEngineController._tickDeck` (`audio_engine_controller.dart`), if `nextPos >= track.duration` (and loop is not active), or when backend reports playback ended:
     - `_tickDeck` did not explicitly check for end of track against `deck.track?.duration` when using the timer clock or sample clock.
     - `deck.jogAngle` was rotating on every tick where `isPlaying` was true even on the very last frame, and never reset.
- **Fix**:
  1. In `dj_scratch_processor.js`:
     - When `pos >= this.frames - 1` (and not looping):
       - Set `this.playing = false;`
       - Reset `this.position = 0.0;`
       - Send immediate position report with `frame: 0`, `playing: false`.
  2. In `deck_audio_backend_web.dart`:
     - In worklet message handler, when `!playing` is reported from end of track: set `_playing = false; _positionFrames = 0.0;`.
     - In buffer source fallback, listen to `src.onended`: when finished, `_playing = false; _positionFrames = 0.0; _stopBufferSource();`.
  3. In `deck_audio_backend_io.dart`:
     - On `_player.onPlayerComplete`: `_playing = false; await _player.seek(Duration.zero);`.
  4. In `audio_engine_controller.dart`:
     - In `_tickDeck`:
       - Check if `track != null` and `track.duration > Duration.zero`:
         - If `!deck.isLoopActive && nextPos >= track.duration`:
           - Track has completed!
           - Set `stillPlaying = false`.
           - Set `nextPos = Duration.zero`.
           - Set `deck = deck.copyWith(isPlaying: false, position: Duration.zero, isCued: true);`
           - Tell backend: `backend.pause(); backend.seek(Duration.zero);`
           - Ensure `jogRot` does not advance.
       - Also, if `deck.isPlaying && !stillPlaying`:
         - Stop jog wheel rotation: `jogRot = deck.jogAngle`.
         - Reset needle/cursor to `Duration.zero` if at or near duration.

---

### Issue 2: Disable Contextual Menu on All UI and Prevent Text Copying
- **Root Cause**:
  - Default browser behavior allows right-clicking to open the browser context menu ("Inspect", "Save as...", etc.) and double-clicking or dragging to select and copy text labels.
- **Fix**:
  1. **Flutter Framework Level (`mobile/lib/main.dart`)**:
     - Call `BrowserContextMenu.disable()` on web startup via `package:flutter/services.dart`.
     - In `DJProMasterApp.build` / `MaterialApp.builder`, wrap the app in:
       ```dart
       builder: (context, child) => SelectionContainer.disabled(
         child: child ?? const SizedBox.shrink(),
       )
       ```
     - This disables Flutter text selection handles, magnifier, copy toolbar, and copy shortcuts globally across all platforms.
  2. **Web Page Level (`mobile/web/index.html`)**:
     - Add CSS rules to prevent text selection and highlight:
       ```css
       *, *::before, *::after {
         -webkit-touch-callout: none !important;
         -webkit-user-select: none !important;
         -khtml-user-select: none !important;
         -moz-user-select: none !important;
         -ms-user-select: none !important;
         user-select: none !important;
         -webkit-tap-highlight-color: transparent !important;
       }
       ```
     - Add capture-phase JavaScript event listeners to swallow:
       - `contextmenu`: `e.preventDefault(); return false;`
       - `copy`, `cut`: `e.preventDefault(); return false;`
       - `selectstart`: `e.preventDefault(); return false;`
       - `dragstart` (on non-slider elements): `e.preventDefault();`

## 3. Step-by-Step Implementation

1. **Update `mobile/web/dj_scratch_processor.js`**:
   - Handle song completion: reset `position` to 0, `playing = false`, force report.
2. **Update `mobile/lib/features/audio_engine/deck_audio_backend_web.dart` & `deck_audio_backend_io.dart`**:
   - Handle buffer source completion and worklet end report with position reset to `Duration.zero`.
3. **Update `mobile/lib/features/audio_engine/audio_engine_controller.dart`**:
   - Add track completion detection in `_tickDeck`.
   - Freeze jog angle when stopped and reset position to `Duration.zero`.
4. **Update `mobile/lib/main.dart`**:
   - Add `BrowserContextMenu.disable()` and `SelectionContainer.disabled`.
5. **Update `mobile/web/index.html`**:
   - Add CSS and JS event listeners for `contextmenu`, `copy`, `cut`, `selectstart`.
6. **Testing & Verification**:
   - Run unit tests with `flutter test`.
   - Run `flutter analyze` to ensure 0 errors.
   - Build and deploy to production via `./deploy.sh`.
   - Verify on `https://dj-mixer.cloud`.
