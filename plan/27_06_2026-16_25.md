# Plan: Improved EQ Section with Reusable Rotary Knobs and Master Bypass

This plan outlines the design and implementation of a professional channel strip for the DJ Mixer, replacing the current vertical sliders with high-fidelity rotary knobs and adding a master EQ bypass switch with a glowing red LED indicator.

## 1. Architectural Changes

### A. Core Atom: `Knob.tsx`
We will create a reusable `Knob` component in `src/components/Knob.tsx` with the following features:
- **Interaction**: Vertical pointer drag (up increases, down decreases) for intuitive touch and mouse control. Double-click resets to default center value (`50` or `0 dB`).
- **Aesthetics**: Premium SVG layout with a metallic bezel, center rotating pointer, and surrounding bipolar tick marks.
- **Bipolar rendering**: Ticks glow from center (12 o'clock / `50`) out to the current value, matching real-world EQ hardware.
- **Sizing**: Responsive sizes (default 28px - 32px) to fit the narrow mixer columns.

### B. EQ Bypass Support
We will extend the audio engine and state to support bypassing the EQ chain (flat response) without losing knob positions:
- **`AudioEffects.ts`**:
  - Add internal memory for `lowGainVal`, `midGainVal`, and `highGainVal` (initialized to `50`).
  - Add an `eqBypassed` boolean state.
  - Implement `setEQBypassed(bypassed: boolean)` that sets the `BiquadFilterNode` gains to `0` when bypassed, and restores their actual values when enabled.
- **`DeckState` / `useDeck.ts`**:
  - Add `eqBypassed` to the deck state.
  - Expose `setEQBypassed` through the controls returned by `useDeck`.
- **`App.tsx`**:
  - Add a handler `handleEQBypassChange(deckId, bypassed)` to update the audio bypass status.

## 2. Component Design & Layout

We will rebuild the EQ channel strip in `src/components/Mixer.tsx` for each deck column (`CH A` / `CH B`):
1. **EQ Header & Bypass**:
   - A row with the label "EQ" and a rectangular button containing a red LED indicator.
   - Glows vibrant red when EQ is enabled (`eqBypassed` is false).
2. **Channel Controls**:
   - Renders 5 stacked rows: `GAIN`, `HI`, `MID`, `LOW`, and `FLTR`.
   - Each row has a small header row: control label (e.g. `HI`) on the left, and a small action button on the right (red `K` for kills, blue `ON` for filter toggle).
   - The rotary `Knob` is centered underneath.
