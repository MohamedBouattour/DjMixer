# Feature Plan: Mac 13 UI Optimization, Audio Playback Resilience, and Crossfader Fix

## 1. Objectives & Overview
Address the three core issues reported by the user on Mac 13 (laptop display ~1280x800 / 1440x900):
1. **Crossfader Jumping Fix**: Eliminate jumping to the right upon drag initiation. Track relative grab offset with precision cursor tracking, matching visual cap geometry and center detent snap.
2. **Media Playback Fix**: Fix Play button not working after media load. Provide valid demo audio asset files (`track_a_demo.mp3`, `track_b_demo.mp3`), make `loadTrack` resilient to missing/buffering sources, update `togglePlay` with immediate optimistic UI update and robust fallback so the virtual audio clock and real audio player operate in harmony without uncaught exceptions blocking transport.
3. **Mac 13 Pro UI Optimization**: Re-architect the landscape layout to fit comfortably on 13-inch Mac screens without awkward scrolling or hidden performance tools. Position performance tool sections (Hot Cues, Loops, Sampler, AI Stems, XY FX) beneath each deck or in an integrated dock, optimize mixer vertical footprint, and ensure Pioneer CDJ-style layout elegance.

## 2. Root Cause Analysis

### Issue 1: Crossfader Drag Jump
- **Cause**: `CrossfaderSlider` lacked `onHorizontalDragStart`, used `context.findRenderObject()` which referenced the parent Column rather than the slider container, mismatched thumb width (`36` vs `44` vs `40`), and applied an arbitrary `(localPos.dx - 20)` subtraction.
- **Fix**:
  - Implement `onHorizontalDragStart`, `onHorizontalDragUpdate`, and `onTapDown` using `details.localPosition.dx`.
  - Calculate `_dragOffset` when the thumb is grabbed, ensuring the thumb stays locked beneath the cursor at the exact grab point (zero jump).
  - Use exact geometry: `maxTravel = width - thumbWidth - 8.0`.
  - Add smooth magnetic center detent (`pos.abs() < 0.04 => 0.0`) and double-tap snap to center.

### Issue 2: Play Button Not Working After Media Loaded
- **Cause**:
  1. Default demo tracks referenced `assets/audio/track_a_demo.mp3` and `track_b_demo.mp3`, which were missing from the disk, throwing uncaught asset exceptions on load.
  2. `AudioEngineController.togglePlay` had no `try/catch` and called `setPlaybackRate` and `resume()` before the audio element was initialized, causing unhandled platform exceptions that prevented `isPlaying` from becoming `true`.
- **Fix**:
  - Copy real, high-quality audio files from `mobile/assets/audio/` to `track_a_demo.mp3` and `track_b_demo.mp3`.
  - Ensure `loadTrack` sets deck state immediately so title, waveform, BPM, and cues are loaded with zero delay, with safe player source configuration in a try/catch.
  - Implement optimistic `isPlaying` toggling in `togglePlay` with comprehensive exception handling so transport clock, jog wheel rotation, and waveforms immediately spin, and hardware player resumes or plays.

### Issue 3: Mac 13 UI Layout & Spacing
- **Cause**:
  - `_buildLandscapeLayout` in `dj_workspace_screen.dart` nested `PerformanceTabsView` under `MixerView` inside a scrollable center column, pushing it completely offscreen below the fold while leaving vast empty space under Deck A and Deck B.
  - Mixer vertical height (~550px) pushed the crossfader to the very bottom margin on 13-inch displays (~700-800px viewport height).
- **Fix**:
  - Re-engineer `MixerView` with sleek, compact pro dimensions (knob size 32-34, fader height 85, crossfader width 240, clean spacing) fitting cleanly in ~440px.
  - Place dedicated Performance Pad bars (Hot Cues, Loops, Stems, Sampler, XY FX) directly below Deck A and Deck B (or an expandable bottom performance dock), matching Pioneer DDJ-FLX10 / Rekordbox layouts.
  - Adjust Jog Wheel to 160px with crisp responsive tactile needle glow, ensuring 100% of controls are visible and operable without vertical scrollbars.
