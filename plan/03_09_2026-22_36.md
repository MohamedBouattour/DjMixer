## 1. Executive Summary & Vision

The objective is to build a complete, production-grade, ultra-low-latency dual-deck DJ and audio mixing mobile application in Flutter for iOS and Android (as well as macOS/Web support for testing). The application rivals industry-standard DJ software (such as Algoriddim djay Pro, Pioneer Rekordbox Mobile, and Traktor DJ), engineered with a component-driven architecture, high-fidelity dark neon club aesthetics, real-time DSP audio processing, 4-stem real-time separation, split-cue monitoring, virtual vinyl jog wheels with scratch physics, 16-pad sampler, BPM transient beat-grid analysis, XY multi-FX, session recording, MIDI hardware mapping, and Ableton Link tempo synchronization.

## 2. System Architecture & Tech Stack

### 2.1 Core Framework & Tooling
- **Framework:** Flutter 3.47.2+ with Dart 3.13.2 (Sound Null Safety).
- **Architecture Pattern:** Clean Architecture + Feature-First Domain-Driven Design with Component-First UI Isolation.
- **State Management:** Riverpod / ValueNotifiers / StateNotifier for high-frequency 60fps audio-reactive UI bindings without unnecessary widget rebuilds.
- **Audio DSP Engine:** 
  - Real-time WebAudio / AudioGraph DSP pipeline simulation in Dart with `Float32List` / `Int16List` typed audio buffers.
  - Multi-channel audio output interface support (Split Cue L/R routing and 4-channel audio interface routing).
  - Time-Stretching & Pitch-Shifting (Master Tempo / Key Lock) algorithm with phase coherence across $\pm 50\%$ tempo changes.
  - Real-Time Transient Energy Detection for beat-grid calculation and Phase/Beat auto-sync.
  - Biquad filter engine (Low-pass, High-pass, Band-pass, 3-Band EQ with Isolator kill).
  - Real-Time 4-Stem Audio Demixing & Filtering (Vocals, Drums, Bass, Melody).
- **Storage & Caching:** `shared_preferences`, `path_provider`, local track persistence with metadata tags.
- **Network / Proxy:** Direct integration with existing backend proxy (`backend/proxy.js` on port 5001) for YouTube stream search and extraction.

## 3. Detailed Specification by Feature Area

### Area 1: Audio Engine & Performance Core
1. **Low-Latency Audio Processing Pipeline**:
   - Sub-15ms deterministic processing cycle with audio clock scheduling.
   - Dual-buffer ping-pong playback architecture.
2. **Split-Cue Output & Routing**:
   - Routing modes:
     - `Multi-Channel Hardware`: Channels 1 & 2 -> Master Output; Channels 3 & 4 -> Cue / Headphone Monitor.
     - `DJ Split-Cable (Mono Split)`: Left Channel -> Cue / Headphone PFL; Right Channel -> Master House Sound.
     - `Single Stereo Mix`: Master output mixed directly with selectable Cue blend.
   - Master / Cue balance fader, PFL auditioning toggles on Deck A, Deck B, and Sampler.
3. **Real-time Time-Stretching & Pitch-Shifting (Master Tempo / Key Lock)**:
   - Waveform Overlap-Add (WSOLA) time-scale modification keeping pitch invariant over $\pm 50\%$ and $\pm 100\%$ range.
   - Pitch shifting without tempo alteration ($\pm 12$ semitones) with Camelot key matching display.
4. **Transient Detection, Beat-Grid & Auto-Sync**:
   - Dynamic short-time energy / spectral flux onset detection algorithm.
   - Automatic BPM calculation with precision beat grid markers.
   - Quantize snap (1/16, 1/8, 1/4, 1 beat).
   - **Phase Sync**: Snaps phase alignment in real time.
   - **Beat Sync**: Locks BPM and aligns downbeat grid with the active master deck.

### Area 2: Deck Transport & Control
1. **Dual Decks + Expandable 4 Decks**:
   - Decks A and B prominently featured, expandable to C and D via top deck selector tabs.
   - Distinct color themes: Deck A (Neon Cyan `#00E5FF`), Deck B (Sunset Orange `#FF5722`), Deck C (Electric Purple `#B026FF`), Deck D (Acid Green `#00FF66`).
2. **Virtual Vinyl Jog Wheels (3 Modes)**:
   - High-fidelity circular physics with inertial rotation, angular drag, and friction decay.
   - **Vinyl / Scratch Mode**: Direct needle-drop position modulation with dynamic scratch pitch synthesis and backspin sound simulation.
   - **Pitch Bend Mode**: Outer bezel touch slows down or speeds up track momentarily by $\pm 2\%$ to $\pm 8\%$.
   - **CDJ Search Mode**: Frame-by-frame stutter scrub (1/75s audio frames) for ultra-accurate cue selection.
3. **Slip Mode**:
   - Maintains a silent "virtual needle" shadow playhead running at normal speed during scratching, looping, or cueing.
   - Upon release, the active playback jumps seamlessly back to the virtual playhead position.
4. **Transport Controls**:
   - Play/Pause with instant feedback.
   - Pioneer-style Stutter Cue (audition cue point, snap back on release, set cue when paused).
   - Temporary Cue (Cup/Cue Play) and Back-to-Start (track head rewind).
5. **Pitch/Tempo Fader**:
   - Vertical slider with center zero detent and zero LED indicator.
   - Selectable ranges: `±4%`, `±8%`, `±16%`, `±50%`, and `±100% WIDE`.
   - Manual Tap Tempo button averaging the last 4 taps.

### Area 3: Mixing Console & Routing
1. **Channel Faders & Peak Limiter**:
   - 0-100% logarithmic volume faders with soft-knee limiter preventing clipping.
   - Stereo 12-segment LED VU meters (-20dB to +6dB) with green, amber, red clip indicators.
2. **Pro Crossfader**:
   - Horizontal crossfader with 3 selectable response curves:
     - *Linear*: Smooth equal-power blend.
     - *Exponential*: Gradual transition.
     - *Sharp Cut (Logarithmic)*: Scratch cut within 1.5mm.
   - Hamster Switch (Crossfader Reverse) to swap Deck A & Deck B.
3. **3-Band EQ per Deck**:
   - High, Mid, Low rotary dials.
   - Modes: *Standard EQ* (-26dB to +6dB) and *Isolator Mode* ($-\infty\text{ dB}$ kill to +6dB).
   - Instant Kill buttons for High, Mid, Low.
4. **Combo Bipolar Filter**:
   - Center 12 o'clock = Neutral bypass.
   - Counter-clockwise = LPF down to 20Hz.
   - Clockwise = HPF up to 20kHz.
   - Adjustable resonance Q control.
5. **Master & Booth Controls**:
   - Master volume dial, Master limiter status, Booth output level attenuator.

### Area 4: Performance & Creative Tools
1. **Hot Cue Management**:
   - 8 illuminated Hot Cues per deck with custom colors and timecode labels.
   - Trigger mode and Delete (`DEL`) mode with quantize snap.
2. **Auto-Looping & Manual Looping**:
   - 1/64, 1/32, 1/16, 1/8, 1/4, 1/2, 1, 2, 4, 8, 16, 32 bars instant auto-loops.
   - Halve (`/2`), Double (`x2`), Loop In/Out nudge controls.
   - **Loop Roll / Bounce**: Momentary slip loop triggered while pressing pad.
3. **Beat Jump**:
   - Directional jumps backward/forward by 1/2, 1, 2, 4, 8, 16, 32 beats.
4. **Integrated 16-Slot Pad Sampler**:
   - 4 banks (Bank A: Vocal Stabs, Bank B: Drum Kits, Bank C: DJ Drops, Bank D: FX Risers).
   - Pitch adjust ($\pm 12$ semitones), individual pad volume, one-shot/hold/loop modes.
5. **XY Touch FX & Multi-FX Rack**:
   - Interactive 2D touch pad controlling Rate/Frequency on X and Depth/Resonance on Y with glowing particle trail.
   - Effects: BPM-synced Echo/Delay, Reverb, Flanger, Bitcrusher, Brake, Roll, Filter Sweep.
6. **Real-Time AI Stem Separation**:
   - Splits loaded tracks into 4 stems: **Vocals**, **Drums**, **Bass**, and **Melody**.
   - Individual stem volume faders, Solo, and Mute buttons per deck.
   - Color-coded multi-layer stem waveforms.

### Area 5: Library Management & Audio Sources
1. **Dual Storage & Cloud Sources**:
   - Local audio files import (MP3, WAV, FLAC, AAC, AIFF, OGG, M4A).
   - Cloud sync integration (iCloud Drive, Google Drive, Dropbox) architecture.
   - YouTube Audio Proxy API client: connects to backend proxy `/api/search` and `/api/stream` for instant track loading and streaming.
2. **Crates & Metadata**:
   - Crates, Playlists, History, Favorites.
   - BPM analysis, Camelot musical key detection, waveform overview preview.

### Area 6: Audio Recording, Hardware MIDI & Ableton Link
1. **Lossless Direct-to-Disk Recording**:
   - Real-time 24-bit 48kHz WAV session capture.
   - Live timer, level meter, cue sheet recording with track metadata, export via Share Sheet.
2. **Hardware MIDI Controller Support**:
   - BLE MIDI and USB OTG/Lightning MIDI input support.
   - Presets for Pioneer DDJ-FLX4 / DDJ-200 / Numark Mixtrack Pro / Hercules Inpulse.
   - Interactive MIDI Learn mode for custom hardware mapping.
3. **Ableton Link Integration**:
   - Wireless multi-device tempo synchronization over local Wi-Fi.
